What is this

SAT is an accessibility and SEO panel for development: in vite dev it shows WCAG, WAI-ARIA and SEO issues on the page, next to the elements, each with its source. After npx sat-check init your agent checks its routes with sat_check, fixes the code and checks again; in the panel, Send to agent puts an issue in its queue and shows when the agent has fixed and verified it. With axe-core installed, its rules run too. Here, without a dev server, there is only the panel.

Automated checks find only part of the issues: SAT doesn't certify WCAG conformance, and it doesn't see iframes, canvas, or states that appear after an interaction. What SAT does not do
