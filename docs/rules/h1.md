# `h1`

**Category**: SEO · **Default**: warning

**Source**: [Google Search Central: title links](https://developers.google.com/search/docs/appearance/title-link) · [HTML: headings](https://html.spec.whatwg.org/multipage/sections.html#headings-and-outlines)

## What it checks

The page has an `<h1>` (warning). Several `<h1>` are valid HTML and Google sets no ideal number of headings, so they are not reported; keep the main heading the most prominent one, since Google may use it for the title link.

## Why

The `<h1>` names the page for search engines and for screen reader users, who often jump to it first.

## How to fix

Give the page an `<h1>` with its main title and use `<h2>`–`<h6>` for sections.

```html
<h1>Running shoes</h1>
<h2>Trail</h2>
<h2>Road</h2>
```
