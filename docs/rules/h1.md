# `h1`

**Category**: SEO · **Default**: error

## What it checks

The page has exactly one `<h1>`. A missing `<h1>` and a second `<h1>` are errors; the issue points at the second one.

## Why

The `<h1>` names the page for search engines and for screen reader users, who often jump to it first. Several `<h1>` make the main topic unclear.

## How to fix

Give the page one `<h1>` with its main title and use `<h2>`–`<h6>` for sections.

```html
<h1>Running shoes</h1>
<h2>Trail</h2>
<h2>Road</h2>
```
